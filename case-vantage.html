Vantage

A billing admin console in Vue 3 with the composition API: accounts can be filtered, selected in bulk and changed, plan usage has sparklines, and the audit log keeps a before/after diff for every mutation.

The problem

Bulk changes with an audit trail.

Admin tools fail in boring ways: a bulk action updates twenty accounts and nobody can say which ones, an export ignores the filters, or undo silently drops half the changes.

Vantage is built around those failures: every mutation goes through one store action, every action appends an audit entry with a diff, and export reads the filtered selection.

What we built

Stores first, components second.

  • Accounts table with search, plan and status filters, sorting and row selection.
  • Bulk plan change and suspend actions, with a single undo that reverts the batch.
  • Plan and usage cards with sparklines computed from the same series the table uses.
  • Audit view with field level diffs, actor, time and a link back to the account.
  • CSV export of the current filtered selection, not the whole table.

Security and money

  • Store actions are pure functions over typed data, so the logic is tested without mounting components.
  • Undo is an explicit snapshot of the affected rows, not a re-application of the inverse action.
  • The audit log is append only; a revert is a new entry, which keeps history honest.
  • The exported CSV is generated from the filtered rows so the two cannot disagree.
