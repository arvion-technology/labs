# Arvion Labs

The public gallery at **https://arvion-technology.github.io/labs/** — runnable
open-source projects from [Arvion Technologies](https://arviontech.net).

Every demo is static: open one, click around, no sign-up or API key. Source lives
in the [organisation](https://github.com/arvion-technology).

Built with the shared `_factory` scripts in our workspace: `index.html` is
generated from the project catalog, screenshots are captured from the running
demos with headless Chromium.
